# Huroof Hero 🦸🏽‍♂️📖

A work-in-progress Progressive Web App (PWA) designed to teach Quranic Arabic and the Arabic alphabet in a fun, gamified way. 

## 🌟 Concept (WIP)
* **Gamified Learning:** Bite-sized, Duolingo-style lessons.
* **Interactive Canvas:** A touch-friendly area to practice writing Arabic letters.
* **Quranic Focus:** Tailored towards understanding Quranic vocabulary and grammar.
* **PWA:** Installable directly from the browser with offline capabilities.

## 🛠 Tech Stack
* HTML5, CSS3, Vanilla JavaScript
* PWA (Web App Manifest & Service Worker)

## 🚀 How to run locally
Since this is a vanilla web project, simply serve the root folder using a local web server. 
* Use the **Live Server** extension in VS Code.
* Or run `npx serve` or `python -m http.server` in your terminal.
* Open `http://localhost:XXXX` in your browser.
